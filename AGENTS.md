# For any AI agent

This folder is a back office for a pressure washing business. All instructions are in `CLAUDE.md`: read it first and follow it, then the skill files it points to under `.claude/skills/`. The scripts in `tools/` say how to use them at the top.

It was built for Claude Code (the board is a Claude artifact, and its data tools are Claude's). Without those tools, say so: the owner needs Claude Code to use it.
